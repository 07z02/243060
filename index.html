Web4 Playground

Interactive training repo for Git, API, and Web4 demos.

🚀 Getting Started

Fork this repo, edit files, push changes, and open a Pull Request. Perfect for testing GitHub workflows, APIs, and onboarding new developers.

📂 Project Structure

  • index.html — Landing page
  • style.css — Styles
  • api/ — Python API demo
  • scripts/ — Git practice scripts
  • .github/ — CI/CD + PR templates

💡 Tips & Practice

  1. Edit this page and commit your changes.
  2. Create a new branch and open a PR.
  3. Experiment with API routes in api/app.py.
  4. Test CI workflow by pushing commits.
